# Exercicio-de-Algoritmos-e-Estrutura-de-Dados-1
Atividade básica proposta para lista de estruturas de repetições em algoritmos básicos, na linguagem C.

Enunciado do exercício:
Em uma eleição presidencial existem quatro candidatos. Os votos são informados através de códigos. Os dados utilizados para a contagem dos votos obedecem à seguinte codificação: • 1,2,3,4 = voto para os respectivos candidatos; • 5 = voto nulo; • 6 = voto em branco; Elabore um algoritmo que leia o código do candidato em um voto. Calcule e escreva: • total de votos para cada candidato; • total de votos nulos; • total de votos em branco. Como finalizador do conjunto de votos, tem-se o valor 0.

Para utilizar o programa, baixe o arquivo "ResolucaoExercicio.c" e o coloque em um compilador de C para o executar. Digite valores de 1 a 6 para os votos, como destacado no enunciado, e 0 para finalizar o programa e imprimir as contagens de votos. Não utilize números reais ou que não sejam entre 0 e 6.
